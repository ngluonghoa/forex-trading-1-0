# M2/P0.12 — Synthetic weekly sub-chunks within Forex BID/ASK partition

Approved cross-project improvement 07/11/2026: retain independent Swing Trading and Forex implementations, unify the engineering principle of immutable content-addressed sub-windows, honest incremental savings, no cross-market semantic copying, and causal source/version discipline. Earlier M2/P0.11 AES-GCM fixture sealing remains an independent primitive; this milestone does **NOT** connect newly segmented window tuples to encryption or Google Drive.

**Implemented:** `src/forex_trading/synthetic_weekly_chunks.py` stores *typed synthetic MarketBar tuples in memory only*, grouped by UTC Monday seven-day **storage bucket**. This date does NOT assert broker rollover, Sunday candle, timezone/DST, holiday or session closure; the existing `CachePartition` still isolates provider, broker product, pair, BID vs ASK, timeframe, timezone policy, calendar, aggregation, rights/schema versions. Each window gets content hash via existing `CandleSnapshot.fingerprint` (which binds full bar source revision, OHLC, first-known, quality and stream), plus immutable in-memory fake object pointer. An independent per-partition manifest records sorted week references, generation and prior manifest hash; unchanged weeks reuse immutable references, one revised week creates one new object. Selective fetch of one requested weekly window avoids reading others. The simulator revalidates all selected typed MarketBars as CLOSED, COMPLETE, VERIFIED, causal and with exact partition identity.

**Safety:** The fake store contains Python objects, **NOT persistable encoded Google Drive file bytes**. Previous M2/P0.10 actual connected Drive smoke comprised only two harmless plain-text files; encrypted AES-GCM M2/P0.11 cache remains offline. No real FX source fetch, account rights, real schema time windows, changed-since provider receipts, automatic 5-minute operation, cloud calls, broker orders, or custody/witness claims. In-memory compare-and-advance cannot enforce cross-session cloud atomicity. Missing old window is blocked absent authoritative deletion scope. Hash is not a vendor signature, and the source quality VERIFIED fixture value does not grant storage entitlement.

**Acceptance:** Synthetic unchanged recheck creates zero new weekly objects; append into an old week updates one old week; later new week adds one; old correction versions only affected week; BID vs ASK and pair/provider/calendar partitions remain isolated; stale writer, corruption, wrong pin, unqualified deletion, and future-known bars fail closed. This is not a provider API bandwidth measurement.
