# M2/P0.13 — Forex BID/ASK Backtest execution scenario reference

Approved cross-project improvement 2026-11-07: combine Swing's causal replay/purge/embargo standard with Forex's independent bid/ask, spread, swap and TP/SL execution policy. Forex **must not import the Swing Vietnam T+ or tick/lot/venue tax semantics**. Existing Forex Master Spec §0 and canonical 09 TP/Exit policy remain normative and unchanged.

Implemented read-only **synthetic** reference module `src/forex_trading/fx_execution_scenarios.py` and tests `tests/test_fx_execution_scenarios.py`. Takes independently injected fabricated LONG/SHORT entry and exit receipts, enforces ENTRY_LONG ask / EXIT_LONG bid / ENTRY_SHORT bid / EXIT_SHORT ask, as-of first-known time, same units/pair/quote currency, positive finite Decimal price, explicit quote-currency commission/slippage and signed swap credit/debit. Gross/net PnL computed only for these fictional receipts; spread is already included by quote sides, **never charged twice**. No automatic account-currency conversion, broker fill certification, position/margin policy, actual source/history or order is inferred. Outputs always `fixture_only=true, validated_backtest=false, executable_fill_verified=false, trading_eligible=false`.

The independent bid/ask OHLC level inspector uses BID extremes for LONG exits and ASK extremes for SHORT exits. Stop and TP both touched in the same bar => `AMBIGUOUS_BOTH` (no invented time ordering or fill). Single side high/low touch is a *level-touch classification only*, not a broker confirmation, and should not be treated as a trade event. Rejects inconsistent bid/ask extremes, invalid stop/target orientation, cross-time/cross-source lookahead and missing quote side.

This is NOT a full Forex Backtest engine: still missing validated zone predicates, first-known historical ticks/spreads, broker position ledger, partial exits, swap calendar, variable fees, replay-to-signal adapter, purged walk-forward OOS, slippage calibration, bid/ask correction source rights, risk/portfolio PnL and reproducible run artifacts. Existing paper/real trading, data caching and release guards remain HARD FALSE. An independently reviewed vendor account and authorized historical data are prerequisites for meaningful results.

Next controlled milestone: create testable FX independent walk-forward purge/embargo event leakage audit with DST/session-aware externally supplied calendar (never import VN trading calendar); integrate with signal events only after detector algorithms and approved historical BID/ASK data exist.
